# Combo release notes

## 0.1.1

- Adds Fabric and NeoForge builds for Minecraft 1.21, 1.21.1, 26.1, 26.1.1,
  26.1.2, and 26.2.
- Requires Java 21 on Minecraft 1.21.x and Java 25 on Minecraft 26.x.
- Architectury is required on both loaders. Fabric also requires Fabric API;
  Mod Menu remains optional.

## 0.1.0

Initial release for Minecraft 26.1.2 on Fabric and NeoForge: melee combos and finishers,
timed parry and counter attacks, stealth and silent takedowns, stamina, directional dodge,
combat HUD, impact feedback, statistics, and configurable settings.
